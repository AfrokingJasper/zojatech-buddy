# Zojatech Buddy

A test project for zojatech frontend recruitment.

## Features

- Authentication Flow: Login, Register, verify and resend OTP.
- Dashboard: A Dashbaord layout with 6 routes, 4 of which are inactive with coming soon notifications.
- Notifications: a notifcation modal triggered by the notiifcation icon
- My Portfolio: dashboard overview page displaying anylytical information such as overview double bar charts, Trending posts, Potential members, watchlist, revenue, and trending news
- Chat: chat layout with features like sending text messages, images, files, and audtio recording (simulated using redux-toolkit to manage application state and mock api calls).

## Installation

Clone the repository and install the dependencies:

```bash
# Clone the repository
git clone https://github.com/AfrokingJasper/zojatech-buddy.git

# Navigate into the directory
cd zojatech-buddy

# Install dependencies
npm install
```

## Usage

Create an env.local file and add the env that was sent in the recruitment mail, then start the project with npm run dev.
